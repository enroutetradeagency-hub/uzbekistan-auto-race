# Ishchi xotira: UZBEKISTAN AUTO RACE

## Qabul qilingan qarorlar

- Birinchi natija — Toshkent viloyati uchun ishlaydigan poyga demo; qolgan 11 viloyat data-konfiguratsiya sifatida tayyorlanadi.
- Runtime — Android ekranga mos browser o‘yin. Native APK keyingi paketlash bosqichi bo‘lishi mumkin, biroq hozirgi loyiha WebDev’da o‘ynaladigan versiya.
- 3D sedanlar va muhit prop’lari procedural Babylon mesh’lar bilan tuziladi; fotorealizm hisi yaratilgan material va fon resurslari bilan kuchaytiriladi.
- To‘liq fizik plugin o‘rniga mobil uchun barqaror, sozlanadigan kinematik vehicle model ishlatiladi.
- AI erkin pathfinding qilmaydi; parametrik poyga chizig‘i bo‘ylab harakatlanadi.
- Vizual tekshiruv `?demo` autopilot rejimi orqali bajariladi.
